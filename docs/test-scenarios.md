実ブラウザーでの手動確認シナリオ

1. 初期表示でサンプル間取りを開く。2Dと3Dに同じ部屋・家具が表示され、日本語ラベルが読めることを確認する。
2. 空き位置に部屋を作成する。寸法を編集し、隣室に接する位置は作成可能、重なる位置は拒否されることを確認する。
3. 家具カタログからソファを選び、2Dに配置する。3Dへ切り替え、同じ場所・色・向きで表示されることを確認する。
4. ソファを移動・回転する。部屋からはみ出す操作が拒否され、正常な操作は2Dと3Dへ同期されることを確認する。
5. 家具または部屋を削除する。Undoで復元、Redoで再削除し、Undo後に別の編集を行うと古いRedoが使えないことを確認する。
6. 保存してページを再読込する。名前・部屋・家具・回転・色が復元されることを確認する。
7. localStorageの保存データを不正なJSONに変更して再読込する。画面がクラッシュせず、初期データまたは回復可能な状態になることを確認する。
8. 3Dで回転・ズーム操作を行い、操作後にも家具が選択可能なことを確認する。WebGLを無効にした場合は説明が表示されることも確認する。
9. デスクトップ幅と狭い画面幅でパネルや主要ボタンが欠けないこと、キーボードで主要操作へ到達できることを確認する。

実装後に各操作のUIが確定したら、上記の主要フローをブラウザー自動テストへ移す。
